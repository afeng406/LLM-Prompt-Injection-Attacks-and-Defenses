# LLM Prompt Injection Attacks and Defenses

LLM 应用提示注入攻防课程实验。首版目标是搭建单轮问答服务，测试直接注入和资料注入，并对输入过滤、资料分区、输出审查进行分档评估。

**当前状态：设计与 AI 编程 Harness 已完成；应用代码、真实模型调用和实验结果尚未实现。**
